# 开发者章程

向源站登记的是 ZIP 或外部 HTTPS 地址，不是把源码留在授权服务器上。不合规的 ZIP 不会落盘。

## 登记表单

开发者面板「登记插件」或「登记模板」：

| 表单 | 说明 |
| --- | --- |
| 应用 | 必选。目录按应用隔离 |
| 分类 | 必选。插件用「其他」等插件分类；模板用「首页模板」 |
| 名称 | 最长 100 字 |
| 标识 | 可按名称生成。提交后不能改。规则见插件清单 |
| 版本 | 例如 `1.0.0` |
| 售价（元） | 默认 0，按元填写，最多两位小数。请求字段是 `priceCents`（分）。0 为免费。大于 0 只能买断，可上传 ZIP，或填写 HTTPS 外链由本站立即拉取并私有托管。价格不写进 `plugin.json` / `template.json` |
| 包来源 | 「上传 ZIP（本站托管）」或「外部 HTTPS」 |
| 地址 | 插件是下载地址，模板是模板地址。上传成功后自动填写且不能手改 |
| 校验码 (SHA256) | 64 位十六进制。上传由本站计算。免费外链可点「自动计算」，跨域失败时在本地用 `sha256sum` 粘贴。付费 HTTPS 外链保存时由本站拉取后自动计算，不用手填 |
| 简介 | 表单可空。ZIP 里的清单 `description` 仍必填 |
| 高级：作者 | 只读，用当前登录开发者名称 |
| 高级：图标 | 仅插件，可空 |
| 高级：更新说明 | 可空，最长 2000 字 |

先「保存草稿」。地址和 SHA256 都有了再「提交审核」。缺其中一项时，提示填写下载地址或模板地址以及校验码。

上传接口：`POST /api/v1/source/developer/packages/upload`，表单字段 `file`，以及 `kind` 为 `plugin` 或 `template`。通过后返回本站 URL 和 `sha256`。

## 两种包

- 插件：ZIP 内是 `plugin.json`。`kind` 可省略；若填写必须是 `plugin`。
- 模板：ZIP 内是 `template.json`。`kind` 必须是 `template`。

清单放在 ZIP 根目录，或只套一层子目录。机器可读规则：`GET /software-source/package-schema.json`（管理员也可 `GET /api/v1/source/admin/packages/schema`）。

不要用内置插件 id：`epay`、`epay-v2`、`alipay-f2f`、`alipay-realname`、`kuaitong-realname`、`tencent-realname`、`xiaomu-realname`。登记这些 id 会返回「不能覆盖内置插件标识」。

## 外链与本站托管

- 上传：本站保存 ZIP，回填地址和 SHA256。提交审核时只核对本地文件，不访问外网。
- 免费外链：必须是 `https://`。提交审核时检查能下载、内容是 ZIP，且 SHA256 一致。公网地址不能指向私网、链路本地或云元数据。写成字面量回环或私网 IP 的源才允许 HTTP 和私网，开发者登记的外链不要依赖这一点。
- 售价大于 0：可以上传 ZIP，也可以填写 HTTPS 外链。填写外链时，保存草稿就会立即拉取 ZIP，走和上传相同的校验，通过后写入付费私有目录并自动计算 SHA256。失败返回中文原因，不落库。相对路径或非 HTTPS 地址会被拒绝：`付费条目请上传 ZIP，或填写 HTTPS 外链由本站拉取托管`。明文 `http://` 会被拒绝：`来源外链必须是 https:// 地址`。私网、回环、链路本地、云元数据，以及重定向到这些地址，都会拒绝。外链只出现在开发者和源站管理员看到的「来源外链」。公开 `index.json`、商店目录和买家下载链接都不包含这条外链，也不包含私有包引用。买家安装仍走授权核对和 10 分钟签名下载。已托管的条目可以点「重新拉取」更新包；失败时保留旧包。来源外链暂时打不开时，条目不会被下架，界面提示「来源外链不可用，重新拉取将失败」。年付会被拒绝：`年付尚未开放，当前只支持买断`。请求里的 `billing: "permanent"` 会记成 `one_time`；价格为 0 时记成 `free`。付费条目当前不能上架：`付费条目暂不能上架，购买与交付将在后续版本开放`。公开 `index.json` 对付费条目保留名称、简介和 `priceCents`，不给出 `downloadUrl`、`templateUrl` 或 `sha256`。

## 审核之前

草稿和已驳回可以改、可以再次提交。待审核、已通过、已上架之后，换包请走「版本」，不要改已发布地址。价格大于 0 的条目当前不能上架。
