# 新版本

已有正式版本之后，包地址在「版本」里新增，不要改当前已发布的地址。界面会提示：已有正式版本后，包地址请通过「版本」新增。

## 新增一条

1. 打开该插件或模板的「版本」。
2. 「新增版本」，填写版本号、包来源（上传压缩包或公开地址）、地址、SHA256、更新说明。收费包由本站保管。按钮不可用时，弹窗里有中文原因。
3. 保存草稿，再提交审核。

免费新版本用公开地址。已标价时，新版本上传 ZIP 由本站托管，或粘贴私有仓库的 Release 资产链接。公开地址不能收费。本站托管的外链要更新包时点「重新拉取」；失败时保留已托管的旧包。私有仓库不在本站留 ZIP。

版本状态：

| 状态 | 界面 |
| --- | --- |
| `draft` | 草稿 |
| `pending` | 待审核 |
| `published` | 已发布 |
| `deprecated` | 已弃用 |

与列表里「当前」标记相同的那条，是目录正在指向的 latest。

## 审核通过之后

管理员通过后，该版本可以成为 latest。旧版本仍留在列表里，可以弃用。源站不保存你的 git 仓库，因此没有「删除源码」这一步。

公开 `index.json` 只展示当前 latest（含 version、downloadUrl 或 templateUrl、sha256，以及可选 changelog）。管理员可以把 latest 指回先前已发布的版本。下架是把整条从公开目录隐藏，不会卸载已经装到其它站点上的文件。
