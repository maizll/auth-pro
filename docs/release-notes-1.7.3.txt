auth-pro 1.7.3

- 后台用「存储管理」取代原来的收费仓库和发布仓库设置，可配置多个位置并指定主存储、备用或停用。
- 支持 GitHub 私有仓库、Gitee 私有仓库，以及阿里云 OSS、腾讯云 COS、Cloudflare R2、MinIO 这类 S3 兼容存储。
- 上传先写主存储，失败再试备用；可选同时写入备用。下载按顺序回退，对象存储使用短时签名地址。
- 令牌和密钥加密保存，页面只能更换，不能查看。
- 超过单文件上限的安装包自动分片，下载时拼合后核对 sha256。GitHub 按 2 GiB、Gitee 按 100 MB、对象存储按 5 GiB。
- 可以按存储浏览文件、查看压缩包里的清单和说明、下载、校验、复制和删除，并标出没有对应条目的文件。
- 每小时检查存储能否连接、安装包是否还在；出问题只提醒管理员，不会自动下架。
- 已经填过的收费仓库和发布仓库会自动变成列表里的两条，不用重新粘贴令牌。
