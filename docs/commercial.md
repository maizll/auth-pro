# 商业版

免费版只限制一件事：最多创建 1 个授权应用。已经存在的应用不会被删除或停用，授权校验 `POST /api/license/verify` 也不看商业版。商业版不限应用数量，有效期内官方付费插件和首页模板显示为已包含，可一键安装，不会在升级后自动全部安装。

界面上的限制必须同时有图标和文字，使用共享组件 `CommercialMark`（默认皇冠图标）。不能只禁用按钮，也不能只弹出一句没有图标的报错。

| 位置 | 表现 |
| --- | --- |
| 应用管理的「新增应用」 | 免费版按钮旁显示皇冠和「免费版仅支持 1 个授权应用，升级商业版可创建多个」 |
| 免费版已经有应用 | 应用页顶部提示条，带同一句话和「升级商业版」 |
| 点击被挡住的操作 | 弹出说明，带图标、文字和「升级商业版」 |
| 后端 `402` / 「该功能需要商业版」 | 全局通知，带图标、说明和「升级商业版」 |
| 商店角标「商业版免费」「已包含」 | 图标加文字 |
| 商店账号条 | 「免费版」，或「商业版」加到期时间。离线宽限或域名不一致时改用警告图标和文字 |

「升级商业版」打开后台里的绑定并支付窗口。未绑定账号时，同一窗口先登录（密码只转发，不保存），源站回调本站域名完成校验后再出付款码。不新开网页，二维码由本站绘制。

## 买方怎么升级

1. 在「应用商店」查看账号条。源站根默认 `https://auth.maizll.com`，可在升级窗口的「源站连接」里改成 https 地址，并填写站点公网地址、是否信任反向代理。域名由站点地址或当前访问域名决定，窗口里不能手改。
2. 用源站的用户或代理商账号登录。源站会请求 `https://<域名>/api/v1/public/station-verify/<nonce>`，不跟随重定向，并拒绝内网 DNS、IP、localhost。
3. 选择已启用的永久商业版套餐，扫码支付。订单号以 `PP` 开头。支付成功后源站在查单响应里返回新的 Ed25519 签名快照，本站保存后立即生效。
4. 官方付费插件、模板显示「已包含」，点一次安装。下载票 10 分钟有效，下载时再次核对权益。

快照约每 6 小时刷新。连不上源站时，按快照里的宽限天数继续保持商业版，默认 7 天。明确吊销、退款、到期或主授权失效会立刻回到免费版，不吃宽限。域名和快照不一致时按免费版处理，并在账号条显示警告。

改密码会撤销该账号下的站点绑定（源站可关闭这项）。自助更换产品应用的域名每 30 天一次，管理员不限次数；旧域名上的绑定会撤销。

## 源站管理员

在「源站运营 → 源站设置」填写产品应用标识、免费套餐、离线宽限（1–30 天，默认 7）和商业版功能键（默认 `multi_app`）。

在「商业版设置」添加永久套餐并启用。年付可以保存，但下单会返回「年付尚未开放」。收款沿用本站已配置的在线支付，不使用余额。支付完成页是源站自己的 `/store/pay-complete`。

「商店订单」可退款。「主授权与权益」可授予或吊销商业版。商业版收入记入 `store_revenue_ledger`，费用比例 10000，立即结算给平台。

签名私钥不要放进仓库。源站进程读取环境变量 `AUTH_PRO_STORE_SNAPSHOT_PRIVATE_KEY`，或数据目录 `store/snapshot-ed25519.key`。私钥必须与程序内置公钥成对。买方只验签，改数据库不能伪造商业版。

第三方开发者的付费条目仍然不能上架。源站管理员名下（`developer_id = 0`）的托管 ZIP 或内置交付可以上架。单件购买和第三方分成不在这一版。
