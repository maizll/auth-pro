# 交付与部署（给买家）

产品版本以仓库根目录 `VERSION` 为准，当前 **1.9.1**。本目录是卖给客户的安装与上线说明，和运维向的 [部署手册](../deployment.md) 并列：这边讲「买到什么、怎么装、怎么自检」；那边讲脚本细节与回滚。

| 文档 | 内容 |
| --- | --- |
| [交付说明](交付说明.md) | 买到什么、环境要求、宝塔一条命令安装、首次登录、导入客户端版本、商业版与当面付、在线更新、备份恢复、常见问题 |
| [Docker 部署](docker.md) | Dockerfile + Compose（MariaDB + 应用）、端口、数据卷、升级；与宝塔路径并列，不要混用同一站点目录 |
| [管理员检查清单](管理员检查清单.md) | 上市前自检 |

两条安装路径任选其一：

1. **宝塔**：本机已有面板、Nginx、MySQL 时，用官网 `install.sh` 一条命令建站。
2. **Docker**：本机已有 Docker Compose 时，用 `deploy/docker/` 起 MariaDB 与应用容器。

不要把 Docker 的数据目录指到正在跑的宝塔网站根，也不要在同一域名上两套进程抢端口。
