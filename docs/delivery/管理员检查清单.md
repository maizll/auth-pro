# 管理员检查清单（上市前自检）

在把站点交给最终用户或对外宣传前，按顺序勾选。宝塔与 Docker 两条路径通用；仅某一路径适用的项已标明。

## A. 安装与进程

- [ ] 产品版本与购买约定一致（后台「在线更新」或 `/api/system/version`）。
- [ ] 存在 `install.lock`，安装向导不可再写入。
- [ ] 管理后台可用超级管理员登录；已修改初始随机密码。
- [ ] （宝塔）进程守护为 RUNNING；`--status` 显示 www 可读 `db.json`。
- [ ] （宝塔）Nginx 已反代到后端，且已拦截 `/backend/`、`db.json`、`install.lock`、`jwt.secret` 等敏感路径。
- [ ] （Docker）仅映射应用端口；MariaDB 未对公网暴露；`.env` 口令已改且权限收紧。
- [ ] 生产访问走 **HTTPS**；证书有效。

## B. 安全与密钥

- [ ] `db.json`、`jwt.secret` 权限为仅所有者可读（常见 `600`），不在可下载的静态目录中。
- [ ] 已异地备份：数据库 + 数据目录关键文件（含 `install.lock`）。
- [ ] 应用的 `appSecret`、支付商户密钥、SMTP 密码未写入文档、仓库或聊天记录。
- [ ] 管理员与角色菜单已收敛；不需要的菜单已隐藏。

## C. 业务就绪

- [ ] 至少一个授权**应用**已创建；测试用 `appKey` 完成一次 `POST /api/license/verify`（或 SDK 示例）。
- [ ] **版本管理**中已导入/上传需要的客户端版本说明与包。
- [ ] **套餐 / 卡密 / 授权**流程按售卖方式抽测通过（用户端或代理端下单/开码）。
- [ ] 若出售商业版：应用已勾选「作为本站商业版出售」，套餐价格大于 0，支付可用；用正式 https 域名打开顶栏购买窗口验证。
- [ ] **支付配置**：易支付或当面付等已按实际开通填写；异步通知地址已在服务商处配置；用小额测一笔并确认订单状态。
- [ ] （可选）邮件 SMTP 发送测试通过。
- [ ] （可选）软件源 / 应用商店条目按需要上架；广告位若不用可保持空。

## D. 更新与运维

- [ ] 已知晓升级方式：宝塔用「在线更新」或官网 `upgrade`；Docker 用换镜像并保留数据卷。
- [ ] 已演练一次备份；恢复命令或步骤有书面记录。
- [ ] （宝塔）若曾出现在线更新权限问题，已执行 `--repair-update-perms` 并复查。
- [ ] 监控或至少定期查看应用日志与磁盘空间（更新备份会占用磁盘）。

## E. 对外说明

- [ ] 给业务方的接入文档只含本站域名与 `appKey` 用法，不含服务器口令。
- [ ] 客户可见文案中不出现内部代码托管地址；更新入口指向本站后台或官网说明。

全部勾选后再切换 DNS 或对外放量。未通过项不要用「先上线再补」跳过支付与备份相关项。
