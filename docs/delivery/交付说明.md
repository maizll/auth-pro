# 交付说明

面向已购买 auth-pro 的客户。安装包与安装脚本从**官网**获取；后台「在线更新」也只连官网，页面上不会出现代码托管地址。

当前产品版本 **1.9.1**（以安装包内 `version.json` / 后台「在线更新」页为准）。

## 1. 买到什么

| 内容 | 说明 |
| --- | --- |
| 授权中心程序 | Linux amd64 发布包 `auth_pro-full-vX.Y.Z.tar.gz`：管理后台、代理端、用户端、开发者面板，以及业务系统调用的授权校验 API |
| 安装入口 | 官网一条命令脚本（不在发布包里），负责宝塔建站、建库、反代、进程守护 |
| 在线更新 | 超级管理员可在后台检查并安装官网新版本（签名与 SHA256 校验） |
| 文档 | 本目录交付说明、Docker 说明、管理员检查清单；更细的菜单说明见 [管理手册](../admin.md)，商业版规则见 [商业版](../commercial.md) |

发布包解压后是「网站根直接可用」的布局（`index.html`、`assets/`、`backend/auth_pro` 等），规范见仓库 [PACKAGING.md](../../PACKAGING.md)。**包内没有安装脚本**，安装与升级请用官网脚本。

不含：宝塔面板本身、MySQL/MariaDB 安装介质、业务系统源码、支付渠道的商户账号。

## 2. 环境要求

### 宝塔路径（推荐给多数买家）

- 已安装宝塔面板，软件商店中已安装 **Nginx** 与 **MySQL**（或 MariaDB）
- 服务器架构：**Linux amd64**（发布包仅此架构）
- 能访问官网（下载安装包与校验清单）
- 准备一个域名（或先用 IP 测试；商业版绑定要求用正式 **https** 域名打开后台）

脚本**不会**替你安装 MySQL。证书可在安装后于面板申请；申请失败时站点可先走 HTTP。

### Docker 路径

- 已安装 Docker Engine 与 Docker Compose v2
- 同样需要 Linux amd64 主机（或能跑该架构镜像的环境）
- 说明见 [Docker 部署](docker.md)

两条路径**并列**：选一种即可。不要让 Docker 容器与宝塔站点共用同一网站目录或同一后端端口。

## 3. 一条命令宝塔安装

把 `example.com` 换成你的站点域名：

```bash
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- example.com
```

不带参数时显示编号菜单（可粘贴到宝塔终端）：

```bash
curl -fsSL https://auth.maizll.com/install.sh | bash
```

指定端口或网站目录：

```bash
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- example.com --port 19127 --site-root /www/wwwroot/example.com
```

默认网站目录为 `/www/wwwroot/域名`。未写 `--port` 时从 `19127` 起自动找空闲端口。

脚本会：创建纯静态站点、本机数据库账号、Nginx 反代、进程守护，并在本机完成安装向导。结束时打印网址、管理员账号（常见为 `admin`）、随机密码、后端端口和数据库信息，并写入仅所有者可读的文件（终端会给出路径）。请立刻保存该密码。

已有同名站点、非空网站目录、同名数据库，或已有 `backend/install.lock` 时，安装会停下来，避免覆盖。已装站点请改用升级或后台「在线更新」。

更完整的选项（备份、恢复、改端口、卸载、修复等）见 [安装部署](../install.md)。

## 4. 首次登录

1. 浏览器打开安装结束时给出的站点地址（建议尽快配置 HTTPS）。
2. 若走自动安装：使用终端打印的管理员账号与随机密码登录管理后台。
3. 若未自动创建管理员：打开站点会进入**安装向导**，填写 MySQL 连接并创建超级管理员；完成后生成 `install.lock`，安装接口关闭。
4. 登录后立刻修改密码；在「系统设置」中核对站点名称等基础项。
5. 侧栏菜单以「系统 → 菜单管理」为准，由后端下发。

查看已装站点的后台地址与初始账号（需在服务器执行）：

```bash
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- --show-admin example.com
```

忘记密码时可在服务器用官网脚本重设（需 root，且站点已安装）：

```bash
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- --reset-admin-password example.com
```

## 5. 导入客户端版本

业务客户端的版本包在管理后台维护，供用户/代理下载或在线更新客户端：

1. 打开 **应用授权 → 应用管理**，创建应用，保存好 `appKey` / `appSecret`（校验签名用，勿泄露到浏览器前端）。
2. 进入 **版本管理**（或应用下的版本页）：登记版本号、更新说明，上传更新包或填写外部下载地址。
3. 若本站同时作为源站分发「授权系统」类安装包：在对应应用的发布版本中按页面指引导入或上传**官网打好的原包**（不要解开再重打，否则签名校验会失败）。
4. 客户端接入方式见 [API 与 SDK](../api-sdk.md)；在「接入开发 → SDK 示例」可按语言下载接入包。

## 6. 商业版与当面付配置

### 商业版（本站向外出售时）

免费版默认限制：最多新建 **1** 个授权应用（已有应用不会被删；`POST /api/license/verify` 不看商业版）。需要多应用或官方付费插件/模板「已包含」时，在管理后台顶栏点 **升级商业版**，按窗口完成绑定与支付。购买与校验走官网；请用正式 **https** 域名打开后台，本机/内网/http 无法完成绑定。

若你要把**本实例**当作源站、向其他站点卖商业版：

1. **应用管理**中打开「作为本站商业版出售」。
2. **套餐管理**中为该应用添加已启用、价格大于 0 的套餐（天数为 0 表示永久）。
3. **支付配置**中配好收款方式。
4. 细节与界面表现见 [商业版](../commercial.md)。

### 支付（含支付宝当面付）

1. 超级管理员打开 **系统设置 → 支付配置**。
2. 按已启用的支付插件分栏配置：**易支付**、**易支付 V2**、**支付宝当面付**。
3. `epay` 与 `epay-v2` **不能同时启用**；当面付可与易支付同时配置，收银台同一支付方式只保留一条，并优先官方当面付。
4. 网关与异步通知地址由系统生成，页面上为只读；到支付服务商控制台填写这些地址。
5. 插件未启用时对应分栏不出现。商户号、密钥只保存在服务器，不要写入文档或聊天记录。

## 7. 在线更新

1. 使用**超级管理员**登录，打开 **在线更新**。
2. 点「检查更新」，再「立即更新」。程序只向官网读取版本清单并下载安装包，后台**不能**手填更新地址。
3. 安装包会核对 SHA256 与官方签名；失败时会尝试回滚页面与程序。
4. 亦可在服务器执行官网升级（保留运行数据）：

```bash
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- upgrade example.com
```

**不要**把新压缩包直接解压覆盖正在运行的站点。Docker 部署的升级步骤见 [Docker 部署](docker.md)，与宝塔「在线更新」分开理解。

## 8. 备份与恢复

### 宝塔脚本备份

```bash
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- --backup example.com
```

备份目录一般在 `/www/backup/auth-pro/example.com/backup/`，默认只保留最近 3 份（含运行数据与数据库导出）。

恢复（先再备份当前数据，再从指定目录还原）：

```bash
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- --restore example.com --backup-dir /www/backup/auth-pro/example.com/backup/baota-backup-时间-进程号
```

### 你必须自己保管的内容

- 数据目录中的 `db.json`（数据库口令，权限应为 `600`）、`install.lock`、`jwt.secret`
- MySQL/MariaDB 业务库
- 支付密钥、邮件 SMTP 密码、应用的 `appSecret`
- 异地副本（脚本本地备份不能代替）

还原数据库后**不要删除** `install.lock`。更多安全注意见 [安全说明](../security.md)。

## 9. 常见问题

### 登录报数据库连接失败 / www 读不到配置

进程守护通常以 **www** 运行。若 `db.json` 仍是 root 且权限过严，www 读不到会导致登录失败。

- 查看状态（含 www 是否可读 `db.json`）：

```bash
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- --status example.com
```

- 修复进程守护（不改数据库与站点程序）：

```bash
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- --repair-guardian example.com
```

### 在线更新提示无法创建前端备份目录

多为备份目录或网站目录权限未交给 www（例如目录是 `600`，所有者进不去）。执行：

```bash
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- --repair-update-perms example.com
```

该命令会建好 `/www/backup/auth-pro/域名` 并交给 www（只给 `/www/backup` 加进入权限，不开放列目录），把网站目录交给 www，并补上缺所有者 rwx 的目录；**不停站点**，不改数据库和 Nginx。

### 更新后版本不一致或端口仍是旧进程

1. 在宝塔进程守护中**停止**本站，避免杀进程后被立刻拉起。
2. 确认占用端口的是本站 `backend/auth_pro`（例如 `ss -ltnp | grep 19127`）。
3. 只通过守护启动：命令为网站根下 `backend/start.sh`，运行目录为 `backend/`。
4. 查看 `backend/logs/auto_pro.log`。

### 其它常用命令

```bash
# 启动 / 停止 / 重启（只走进程守护）
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- --start example.com
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- --stop example.com
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- --restart example.com

# 修改后端端口
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- --change-port example.com --port 19128
```

帮助全文：

```bash
curl -fsSL https://auth.maizll.com/install.sh | bash -s -- --help
```
