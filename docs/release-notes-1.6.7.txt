auth-pro 1.6.7

顶栏商业版入口按「免费版 / 商业版」分开。未开通先显示灰色小字「免费版」，旁边是主色描边按钮「升级商业版」，左侧是火箭图标，悬停时轻微填充，不再使用黄色。已开通是深色圆角徽章，带对勾盾牌和「商业版」，后面写到期日期；永久授权写「永久授权」。源站暂时连不上、但仍在宽限内时，显示「待校验」和橙色提示点，避免和已开通混在一起。宽度小于 768 时，顶栏只留菜单、商业版入口、通知和头像：未开通只显示「升级」，已开通只显示盾牌和「商业版」，不显示「免费版」和到期时间。语言切换、主题设置和暗色模式改到头像菜单。用户端和代理端手机顶栏同样把暗色模式收进头像菜单，并加大图标间距和点击区域。

购买窗口的横幅改成蓝色渐变。限额提示和授权详情卡里的土黄色换成主题主色。应用商店不再显示版本状态，免费版或商业版只看顶栏。手机上「软件源管理」和刷新挪到标题下方，说明文字保持一行。点击后仍打开原来的购买窗口或授权详情。

源站设置里的收费仓库改成贴上令牌就能配好。点「测试令牌」后自动填入所有者，也可以改选令牌所属的组织。仓库名默认是 auth-pro-paid。仓库不存在时，点「自动创建私有仓库」或直接保存，都会建成私有仓库；已经是私有仓库就直接使用；已经公开则拒绝。细粒度令牌要有 Administration 读写才能创建仓库，还要有 Contents 读写才能上传安装包；经典令牌要有 repo 权限。仓库已经存在时，没有创建权限也可以用。连上之后显示「已连接：所有者/仓库（私有）」。还没配置时，提醒只说明安装包会暂存在本站，以及接下来要粘贴令牌，不再把同一句话写两遍。

应用商店里，还没买的付费插件按钮直接写「购买 ¥X」。点启用或安装会打开购买窗口，可以单独买这一条，也可以升级商业版（包含全部官方付费插件和模板）。商业版不包含的条目只显示单独购买，并写明「商业版不包含此项」。付款码、倒计时和打开付款页沿用原来的购买窗口。付完后会刷新权益并继续启用。

源站如果已经删掉或吊销了绑定，买家再下单、查单、刷新、安装或下载时，会清掉本机的绑定凭据和快照，购买窗口顶部提示「之前的绑定已在源站删除，请重新绑定账号后继续购买」，并回到绑定步骤。绑定成功后回到刚才选的套餐或单品继续付款。打开窗口时如果本地快照已经是明确吊销，也会直接显示重新绑定。窗口里另有「解除绑定 / 重新绑定」。同域名上留下的已删除或已吊销记录不会再报「域名已绑定」。

购买窗口不再提供源站连接设置，也没有「高级」手填。购买网站固定是 https://auth.maizll.com，页面不显示这个地址，也不能用环境变量或配置文件修改。升级会清掉数据库里以前保存的源站地址、站点地址和信任代理。本站域名自动使用当前的 https 访问地址。本机反代只要带上协议（宝塔常见的 Host 和 X-Forwarded-Proto）就会按转发后的域名绑定。识别到本机、内网或 http 时，只提示用正式的 https 域名打开后台后再试，不能在页面上填写。

应用管理页去掉顶部重复的免费版提示，只在「新增应用」旁边留一行说明。已经有一个应用时，再点「新增应用」才弹出升级窗。手机上的应用列表只把「编辑」留在外面，「版本」收进「更多」，操作列固定在右侧。发布仓库令牌还没填写时，只显示一行灰色说明「未配置，上传时需要填 https 外链」。填了一部分，或点保存、测试时，才提示缺所有者、仓库或访问令牌。

这一版删掉了已经下线、但还留在仓库里的旧代码：没有挂到路由的注册页，未使用的快捷入口、表单假数据和空插件入口，以及菜单里已经没有页面的「商业版设置」「商店订单」「主授权与权益」「商业版收入」。同时去掉没有引用的广告位兜底、收费仓库探测、付费包旧暂存、购买报价和商店预留设置等函数。数据库迁移和旧书签跳转都保留，购买和授权的行为没有因此改变。

商店签名公钥没有更换。
