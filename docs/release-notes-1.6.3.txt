添加或刷新软件源时，以 .json 结尾或返回 JSON 的地址按 JSON 目录处理，不再把本站 index.json 当成 Git 仓库克隆。类型和地址不一致时当场改成正确类型并提示。已经记成 Git、地址却以 .json 结尾的旧记录会在启动时改回 JSON，重复执行不会再改。Git 克隆发现不是仓库时，提示「该地址不是 Git 仓库，可能是 JSON 目录，请修改源类型」，不再显示 git 的原始报错。

应用删除或归档后，原来的 /software-source/<旧标识>/index.json 不再被当成空目录。没有把地址转走时，接口返回 HTTP 410 的 JSON，刷新方显示「该软件源对应的应用已删除或归档」，后台可以「恢复应用」或「更换源地址」。归档时可以勾选把该应用的软件源地址转到另一个应用，旧地址继续返回目标应用的目录。1.6.1 之前已经真删的应用，可以在源站设置里把旧标识映射到现有应用，重复保存只更新目标。恢复应用后，这条地址重新返回它自己的目录。

程序内置的默认软件源改为 https://auth.maizll.com/software-source/app_f93896d80066_5811/index.json ，类型是 JSON 目录。升级时只把旧默认地址 https://auth.maizll.com/software-source/app_4e85b4724223_2603/index.json 换成这个地址，并改成 JSON。再启动一次不会重复添加。自己添加的其它软件源保持不动。
