auth-pro 1.6.1

软件目录可以只填公开地址。收费安装包统一放进站长配置的同一个私有 GitHub 仓库。

来源二选一：

1. 公开地址。免费条目保存这条地址，本站不存包。收费条目会拉取一次，校验后放进收费仓库。
2. 上传压缩包。收费条目校验后上传到收费仓库，并删除本站临时文件。

收费仓库只在后台「软件源设置」配置一次：所有者、仓库名，以及一枚 Contents 读写令牌。令牌加密保存，页面不回显明文。站长自己的条目和开发者的条目都用这一枚令牌。开发者不填令牌，也不需要自己的仓库。

买家付款后，本站核对授权，向 GitHub 换一个几分钟过期的地址，买家直接从 GitHub 下载。买家看不到仓库和令牌。客户端仍用 sha256 核对。

还没配置收费仓库时，收费包先暂存在本站，后台用中文提醒去配置。开发者端不显示这句提醒。

令牌失效或文件没了，这条会标红并通知，不会自己下架。

按钮是灰的时候，表单会用中文说明还缺什么。

如果以前有收费条目挂着公开地址，升级后被标成隐藏或弃用，1.6.1 会把它放回草稿，并写上「需要重新上传 zip 或填写公开地址，才能继续收费出售」。已经在卖的、免费的、以及本站托管或已经在收费仓库里的条目不会被改掉。

支付宝当面付的官方插件仍在应用商店和支付配置里，不在软件目录的种子数据中。
