auth-pro 1.6.1

软件目录可以只填公开地址。收费安装包统一放进站长配置的同一个私有 GitHub 仓库。

来源二选一：

1. 公开地址。免费条目保存这条地址，本站不存包。收费条目会拉取一次，校验后放进收费仓库。
2. 上传压缩包。收费条目校验后上传到收费仓库，并删除本站临时文件。

收费仓库只在后台「软件源设置」配置一次：所有者、仓库名，以及一枚 Contents 读写令牌。令牌加密保存，页面不回显明文。站长自己的条目和开发者的条目都用这一枚令牌。开发者不填令牌，也不需要自己的仓库。

买家付款后，本站核对授权，向 GitHub 换一个几分钟过期的地址，买家直接从 GitHub 下载。买家看不到仓库和令牌。客户端仍用 sha256 核对。

还没配置收费仓库时，收费包先暂存在本站，后台用中文提醒去配置。开发者端不显示这句提醒。

令牌失效或文件没了，这条会标红并通知，不会自己下架。

按钮是灰的时候，表单会用中文说明还缺什么。

如果以前有收费条目挂着公开地址，升级后被标成隐藏或弃用，1.6.1 会把它放回草稿，并写上「需要重新上传 zip 或填写公开地址，才能继续收费出售」。已经在卖的、免费的、以及本站托管或已经在收费仓库里的条目不会被改掉。

支付宝当面付的官方插件仍在应用商店和支付配置里，不在软件目录的种子数据中。

软件目录里每条插件或模板可以切换绑定的应用，也可以勾选多条一起切换。版本、价格和安装包跟着走。目标应用里已经有相同标识时会用中文拒绝，不会覆盖。已归档的应用不能再作为目标。

应用下拉里有「未归属（应用已删除）」。这只用来找升级之前就已经对不上任何应用的旧条目。从这一版起，删除应用不会再把条目变成未归属。

删除应用改为归档。应用还在列表里，标成已归档，授权、套餐和版本都还在。下面还有目录条目时，可以先迁到另一个应用再归档，也可以直接归档，条目仍挂在原来的应用上。开发者只能切换自己的条目，目标也只能是自己能登记、且还没归档的应用。

收费安装包从现在起按「存在哪」记账：本站暂存，或站长的私有 GitHub 仓库。每个版本记下位置和校验码。仓库已经配好但上传失败时，这条不会保存，也不会悄悄改存到本站。以后要加别的网盘，只加一种存储方式，不用再改目录本身。说明写在 docs/design/catalog-storage-ownership.md。

弃用后可以恢复为草稿，不会自动上架。已归档的应用可以恢复，原来的授权和版本都还在。授权被禁用后不能再下载收费包。本站暂存的收费包找不到时会通知管理员，条目不会自动下架。

支付宝当面付下单时，网关地址带上 charset=utf-8，避免验签被当成 GBK 失败后页面显示乱码。密钥或 AppID 不对时，后台给出中文原因。
