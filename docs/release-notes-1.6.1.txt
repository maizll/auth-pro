auth-pro 1.6.1

软件目录「上传安装包」只填外部地址时，底部两个按钮不再是灰的。

以前压缩包和外部地址都标成必填，没选 ZIP 就点不了「仅校验解析」和「校验并保存元数据」。1.6.1 起二者二选一：只填 https 网址即可。本站会下载这个 ZIP，检查清单、越界路径和大小，并自动填写校验码。GitHub Release 下载地址会跳转，每一跳都会拒绝内网地址。填 0 元时，目录仍使用你填的地址；填了价格时，本站私有托管，买家看不到外链。

按钮还是灰的时候，弹窗里会用中文说明还差什么，例如还没选应用、地址不是 https，或勾了推送 Release 却没选压缩包。

1.6.0 及更早版本若遇到按钮是灰的：把 ZIP 先下载到手机或电脑，再在弹窗里选择这个压缩包，并勾选「推送 GitHub/Gitee Release」，或者取消勾选后同时填上外部地址。只填外部地址、不选压缩包，在升级到 1.6.1 之前无法保存。
