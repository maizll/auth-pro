auth-pro 1.6.1

软件目录「上传安装包」可以只填地址，收费安装包也不再由本站存文件、走流量。

来源三选一：

1. 公开地址，只用于免费。本站下载校验后不留压缩包，目录继续用你填的 https 地址。
2. 私有 GitHub 仓库，收费推荐。把 ZIP 发到私有仓库的 Release，在弹窗里粘贴资产链接。本站只用一枚只读令牌核对一次，记下校验码，然后删掉临时文件。买家付款后，本站向 GitHub 换一个几分钟过期的地址，买家直接从 GitHub 下载。买家看不到仓库和令牌。
3. 上传压缩包。收费条目仍可以让本站托管 ZIP。

只读令牌在「软件源设置」里的「收费插件只读令牌」。GitHub 上建 fine-grained token，只给目标私有仓库 Contents: Read-only。页面不显示令牌明文。令牌失效或文件没了，这条会标红并通知，不会自己下架。

按钮是灰的时候，弹窗会用中文说明还缺什么。

如果以前有收费条目挂着公开 GitHub 地址，升级后被标成隐藏或弃用，1.6.1 会把它放回草稿，并写上「需要改成私有仓库来源或上传 zip 才能继续收费出售」。已经在卖的、免费的、以及本站托管或私有仓库的条目不会被改掉。

支付宝当面付的官方插件仍在应用商店和支付配置里，不在软件目录的种子数据中。若要在软件目录里出售那份 ZIP，用私有仓库的 Release 链接重新登记。
