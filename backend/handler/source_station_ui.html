本站软件源控制面

本实例作为源站只保存目录元数据与外部 HTTPS 地址，从不存储插件/模板源码。 管理员可上传 ZIP 仅作内存解析：自动读取 plugin.json / template.json 填表并计算 sha256，随后推送到已配置的 GitHub/Gitee Release 或粘贴外部下载地址；包本身立即丢弃。 消费者在「软件源管理」添加 https://<host>/software-source/index.json（兼容 /auth-pro/index.json）。 更新 = 新的外部包 URL + sha256 + 版本元数据，旧版本保留；公开目录只展示 latest。 下架 ≠ 远程卸载：下架只是从公开目录隐藏，已安装到其它实例的包不会被删除。

公开目录

GET /software-source/index.json 无鉴权、无信封；仅 status=published 的条目会出现。
